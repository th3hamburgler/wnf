## Codebase Patterns

- Date format in codebase is `dd/mm/yyyy`
- Raw data has match results as W/L/D1/D2 keyed by date
- D1/D2 both represent draws (team A vs team B perspective)
- Points calculation: W=3, D=1, L=0
- Need Array.from() for Set iteration due to TS target config
- Select component styled with bg-gray-800, border-wheat-100 to match theme
